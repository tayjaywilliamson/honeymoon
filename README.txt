Honeymoon Day Guide — hosted web-app version
=============================================
Files: index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png
Upload ALL of these files to the root of your GitHub Pages repository (or any static host).
Code to open the app: 1124   (change it: search for "1124" in index.html)

Install on iPhone: open the site URL in Safari -> Share -> Add to Home Screen.
Then open it from the icon, tap "Locate" on the map, allow location.
Tap "Save today's maps offline" (or "Whole trip") once while on Wi-Fi.
